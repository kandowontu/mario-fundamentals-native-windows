# Independent visual-reference audit

The native presentation sweep is no longer evaluated only against images generated by the port
itself. When the local reference set is present, `tools/verify_visual_references.py` compares
representative output from all five games in both editions against the newly generated QA frames.

## Reference sets

- Macintosh references are local captures of the supplied original image running in the
  [Internet Archive vMac emulator](https://archive.org/details/mario-fundamentals). The verifier
  removes the stable browser/emulator chrome and reduces the captured game surface to 512x384.
- DOS references are locally retained 320x200 screenshots from the
  [Mario's Game Gallery article](https://www.mariowiki.com/Mario%27s_Game_Gallery). They are an
  independent presentation cross-check; the extracted DOS media and disassembly remain the
  authority for behavior and assets.

The screenshots live below `work/references/`, are excluded from Git and release artifacts, and
are used only for local preservation QA.

## Method and current result

The comparison uses Gaussian-smoothed regional RGB root-mean-square error after normalizing each
image to its edition's logical resolution. Regions containing random pieces, cards, speech-mouth
frames, or the captured mouse cursor are excluded. That makes the test sensitive to scorecard,
board, status-bar, tiled-background, menu, and whole-scene placement regressions without treating
different random game states as failures.

| Edition | Reference case | Current RMSE | Maximum |
| --- | --- | ---: | ---: |
| Macintosh | Backgammon board | 12.674 | 16.0 |
| Macintosh | Dominoes table | 2.335 | 4.0 |
| Macintosh | Checkers chrome | 10.620 | 14.0 |
| Macintosh | Go Fish table | 12.639 | 16.0 |
| Macintosh | Yacht scorecards | 6.110 | 10.0 |
| DOS | Main menu | 8.191 | 11.0 |
| DOS | Backgammon chrome | 30.693 | 34.0 |
| DOS | Dominoes table | 2.068 | 3.0 |
| DOS | Checkers chrome | 22.418 | 27.0 |
| DOS | Go Fish table | 24.395 | 28.0 |
| DOS | Yacht scorecards | 8.509 | 12.0 |

The release gate writes the machine-readable result to
`work/audit/visual-reference-verification.json`. Thresholds are deliberately below the measured
distance to mismatched scenes; the fixed-edge cases also reject small whole-scene shifts. This is
a structural cross-check, not a claim that browser-scaled captures or different random turns are
pixel-identical.
